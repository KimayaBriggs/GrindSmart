#GrindSmart

Grindmart is an AI-powered study habit optimization app designed to help students build better routines, improve focus, and maximixe productivity.

GrindSmart aims to personalize studying using intelligent recommendations based upon user behavior, enviroment, and learning patterns.

##Features (Intended)
- Initial onboarding survey 
- AI-powered study method suggestions
- Study habit tracking
- Productivity analytics
- Smart reminders
- Custom study space optimization tips

##Stack
- Kotlin
- Android SDK
- Firebase (Intended)
- AI Integration (Intended)
